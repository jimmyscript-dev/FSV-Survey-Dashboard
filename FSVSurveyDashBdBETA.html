Dashboard filters

Import a survey summary CSV to replace sample data for this page session. Use one row per class, source, and survey period; the template lists the required columns.

Excel / CSV file requirements

Import an Excel workbook (.xlsx or .xls) or CSV file. The first worksheet (or CSV header row) must use the template column names, with one survey result per row. Excel dates are supported; CSV dates must use YYYY-MM-DD. Use source FE or QUALTRICS and exact period labels (for example, FST W1 or OCP W1). Counts are whole numbers; scores and rating metrics are 0–100. Leave all three NPS counts blank if unavailable. Optional comments can be newline-separated; set comment_type to SIGNIFICANT, GOOD_PRACTICE, OPPORTUNITY, or OTHER.
